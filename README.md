
  # High-fidelity POMO mobile UI

  This is a code bundle for High-fidelity POMO mobile UI. The original project is available at https://www.figma.com/design/OQlQD8X7euE2D9hf4f7x5C/High-fidelity-POMO-mobile-UI.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Deploy to Vercel

  This project is configured as a Vite app for Vercel.

  Vercel settings:

  - Framework Preset: `Vite`
  - Install Command: `npm install`
  - Build Command: `npm run build`
  - Output Directory: `dist`

  Steps:

  1. Upload this project folder to GitHub, GitLab, or Bitbucket.
  2. Open Vercel and choose `Add New... > Project`.
  3. Import the repository.
  4. Keep the detected Vite settings, or use the settings above.
  5. Click `Deploy`.

  You can test the production build locally with:

  ```bash
  npm run build
  npm run preview
  ```

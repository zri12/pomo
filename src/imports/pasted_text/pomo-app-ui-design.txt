A modern, clean, and highly readable mobile app UI design for an IoT-based fuel station monitoring application called “POMO” or “Pom Monitor.” The app is designed to help drivers in Bandung and Cimahi monitor real-time Pertalite stock availability, SPBU queue conditions, and route alternatives, reducing wasted time, fuel, and driving anxiety. The interface should feel smart, reliable, fast, and driver-friendly, with a strong focus on clarity, safety, and quick scanning while on the road.

The overall visual style is a polished high-fidelity mobile application design, suitable for Figma prototyping. Use a professional yet friendly UI/UX aesthetic with rounded cards, soft shadows, clean spacing, smooth transitions, and a modern sans-serif font similar to Montserrat. The main color palette uses deep navy blue (#24408E) and medium blue (#3D5AB9) for branding, headers, navigation, icons, and primary actions. Use a traffic-light style map indicator system: turquoise green (#00A78F) for available stock or short queue, solid yellow (#F8C301) for medium queue, and warm orange (#EF8424) for empty stock or long queue. Avoid harsh red as the dominant warning color; use orange tones to make alerts feel urgent but not visually stressful.

Create the UI in a mobile app format, preferably in a modern Android/iOS frame size such as 390x844 or 430x932. The design should include multiple connected screens: Splash Screen, Sign In, Register, Main Interactive Map, SPBU Bottom Sheet Detail, AI Smart Alert, QR Code Payment, and Logout Confirmation Dialog. All screens should feel consistent, realistic, and ready to be used as a clickable Figma prototype.

The Splash Screen should look unique and memorable. Place the POMO logo in the center using a clean fuel-pump icon combined with a small radar or IoT signal symbol. Add a subtle map-grid background with soft blue gradients and tiny animated-style dots representing nearby SPBU locations. The mood should be modern, trustworthy, and technology-driven.

The Authentication screens should include Sign In and Register pages with a clean white background, navy headers, rounded input fields, and large readable buttons. Include fields for email, password, and user identity where needed. The buttons should use navy blue and medium blue gradients. Add small supportive microcopy such as “Pantau stok Pertalite dan antrean SPBU secara real-time.” The layout must feel simple and not crowded.

The Default Main Screen should immediately show an interactive map after login. The map should display the user’s current location in the Bandung-Cimahi area and show nearby SPBU pins. Use color-coded map pins: green for stock available and queue 0–9 vehicles, yellow or orange for queue 10–15 vehicles, and darker orange for queue above 15 vehicles or stock unavailable. The map should support direct manipulation, visually implying that users can drag, scroll, zoom, and explore the map in all directions. Add a floating search bar at the top with placeholder text “Cari SPBU terdekat...” and a small microphone icon for voice command / hands-free interaction. Include a compact filter chip row such as “Terdekat,” “Stok Ada,” “Antrean Sepi,” and “Buka 24 Jam.”

Add a bottom navigation bar with clear icons and labels: Peta, Riwayat, Bayar, Notifikasi, and Profil. The active state should use navy blue, while inactive icons should use soft gray. Keep the navigation simple, large enough to tap safely, and easy to scan quickly.

When a user taps an SPBU pin, show a Tap-to-Expand Bottom Sheet sliding from the bottom of the screen with a smooth and unique animation feel. The Bottom Sheet should include the SPBU name, address, distance, estimated travel time, Pertalite stock status, queue status, and queue count. Include realistic dummy SPBU examples such as “SPBU 34.405.02 — Jl. Raya Barat Cimahi,” “SPBU 34.405.10 — Jl. Interchange Tol Baros,” or “SPBU 34.405.18 — Jl. Raya Cihanjuang Km. 07.” Use clear status badges such as “Stok Tersedia,” “Antrean Sepi,” “Antrean Sedang,” or “Stok Menipis.” Add a row of facility icons inside the Bottom Sheet, including Mushola, Kamar Mandi, Supermarket, ATM, Isi Angin, and Toilet. Each facility icon should be simple, rounded, and consistent with the blue visual system.

The SPBU Detail section should show a fuel dispenser status card. Use a fuel tank icon with green indicator for “Pertalite Tersedia” and orange indicator for “Pertalite Habis / Menipis.” Display queue logic clearly: green for 0–9 vehicles, yellow/orange for 10–15 vehicles, and darker orange for more than 15 vehicles. Include a primary call-to-action button “Navigasi ke SPBU” and a secondary button “Pesan & Bayar BBM.”

Create an AI Smart Alert UI component that appears as a friendly notification card or modal. The alert should warn the user if an SPBU along the route is predicted to run out of Pertalite soon. Use wording such as “Prediksi stok SPBU tujuan akan habis dalam 20 menit. Rute alternatif tersedia.” Include two actions: “Lihat Rute Alternatif” and “Tetap ke SPBU Ini.” The design should feel helpful and intelligent, not alarming.

Create a QR Code Payment screen for ordering and paying fuel inside the application. The screen should allow users to choose a specific nominal or liter amount, such as Rp50.000, Rp100.000, 5 Liter, or 10 Liter. Do not include any “Full Tank” button. Add clear microcopy: “Pembelian Full Tank harus dibayar langsung di SPBU.” Use rounded amount selector cards and a large primary button “Bayar Sekarang.” After payment, show a clean QR Code ticket screen with order ID, SPBU name, fuel type “Pertalite,” selected amount, and instruction text: “Tunjukkan QR Code ini kepada petugas SPBU.”

Create a Logout Confirmation Dialog as part of the UI system. The dialog should use a soft overlay background and a rounded white card. The message should clearly ask: “Keluar dari akun?” with supporting text “Pastikan aktivitas pemesanan sudah selesai sebelum logout.” Include two buttons: “Batal” and “Ya, Logout.” This supports error prevention and keeps the user from accidentally leaving the app.

The UI should prioritize mobile usability, readability, safety while driving, and low cognitive load. Use large touch targets, strong visual hierarchy, clear iconography, and concise Indonesian microcopy. The map should be the dominant visual element on the main screen, while cards and bottom sheets should feel lightweight and easy to understand. The final result should look like a real smart mobility and IoT fuel-monitoring app, professional enough for a university project presentation, modern enough for a startup-style product demo, and clean enough to be directly recreated or prototyped in Figma.
